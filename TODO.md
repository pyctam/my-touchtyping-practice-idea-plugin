* Consider to offer font selector by using by default these suggested fonts:
    * **Common Serif Fonts with True Small Caps**
        * Many traditional, high-quality serif families include native small caps glyphs rather than relying on software
          to artificially shrink the text.
        * **Georgia**: A highly readable, universally pre-installed system font that includes robust OpenType support
          for true small caps.
        * **Palatino Linotype**: Widely available on both Windows and Mac platforms, featuring perfectly proportioned
          smaller capitals.
        * **Garamond**: A classic typeface found on almost every computer; its small caps retain their elegant, wide
          visual weight without feeling squeezed.
    * **Common Sans Serif Fonts with True Small Caps**
        * True small caps are less common in basic sans-serif families, but a few standard options handle this
          perfectly:
        * **Calibri**: Microsoft's longtime default sans-serif contains built-in OpenType small caps that preserve
          letter width and line thickness.
        * **Verdana**: Designed for screen readability, its wide-set nature ensures that small capitals look
          exceptionally broad and open, never condensed.
    * **Dedicated All-Caps/Small-Caps Fonts**
        * If you want a font where the lowercase letters inherently look like uppercase letters without needing to
          toggle an "OpenType" or "Small Caps" button in your software, look for:
        * **Copperplate Gothic**: A staple system font on almost all computers. It has no lowercase letterforms at all;
          typing lowercase automatically produces smaller, wider, geometric capital letters.
